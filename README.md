# CAD 交付文件

本仓库用于公开交付 CAD 制作深化资料、PDF 预览与零件清单。

## 项目

- [HW73005-L2000 体验桌](hw73005-l2000/)：R01 成型深化稿，未生产放行。

## 生产状态

本版用于成型尺寸和装配基准核对、配作及首件准备。钣金折弯补偿与最终展开下料、到货五金接口、刀形腿净腔约 24.7 mm 与 ≥25 mm 过线铁管的冲突，均需按交付说明完成首件核实。资料公开下载不代表工厂或接收方批准加工。

## 文件与状态

交付页的版本、尺寸、文件可用性与校核结论由对应项目的 `project.json` 统一记录。CAD、PDF、BOM 及 ZIP 均放在项目的 `files/` 目录。`previews/` 存放从正式图纸导出的预览。

不得将待核实内容表述为工厂下单批准或接收方 CAD 验收通过。

## 本地查看

在仓库根目录运行 `python3 -m http.server 8765`，访问 `http://127.0.0.1:8765/`。
