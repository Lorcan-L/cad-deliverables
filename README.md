# CAD 交付文件

本仓库公开交付制作深化图纸、可编辑CAD、两份XLSX与复核说明。

## 当前项目

[HW73005-L2000 体验桌](https://lorcan-l.github.io/cad-deliverables/hw73005-l2000/) 默认展示R02：37页图册、84项BOM、52条采购记录及21条套件子项。R01五项旧文件保留原下载路径，页面提供历史版本入口。

## 验收边界

R02补充八点可拆桌面、四横梁、中央下放检修和五支路电气。发布仍为成型深化稿，未生产放行。展开补偿、结构荷载、成品配装、门盖启闭、防坠与电气实物检验须首件完成；数字回读不等同接收方CAD操作验收。

## 文件结构

project.json统一记录版次、状态、文件大小与SHA256。新文件位于files/R02，旧文件仍在files。预览来自同版正式PDF，制作以完整图纸和说明为准。

## 本地及Pages

在仓库根运行`python3 -m http.server 8765`。GitHub Pages从main分支根目录发布。
